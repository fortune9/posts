🚀 **I turned my past LinkedIn posts into a book — for $0.05!**

I just tried **DeepSeek Harness** (https://deepseek.com/harness/en/), DeepSeek's open-source coding agent, and used it to convert all my past LinkedIn posts into a book. Total cost? **$0.05**. 🤯

It's a web-based agent harness where **"everything is a plugin"** — file editing, shell, web & file search, skills, planning, and subagents, all composed from pluggable components built on the Cordis kernel. I ran it in **Standard mode** (the full coding agent preset).

### ✅ Pros
- 💰 **Absurdly cheap** — a whole book conversion for $0.05
- ⚡ **Fast** — no long waits between steps
- 🔓 **Open source (MIT)** — source included, everything is a plugin

### ⚠️ Cons
- 🐚 **Tool-calling glitches** — my run hit bash tool errors that needed retries

### 🔮 My wish
A **CLI version** like Claude Code, Qwen Code, or Antigravity CLI. The current DeepSeek Harness is web-based, which is great for quick experiments but limits scripting and automation workflows. Still, at $0.05 a task, it's an incredible bargain for light agent work!
