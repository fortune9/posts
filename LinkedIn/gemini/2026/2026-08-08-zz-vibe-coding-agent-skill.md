🚀 **Supercharge your AI agent's coding efficiency with `zz-vibe-coding`!** 🤖

Coding with AI agents is incredible, but we’ve all hit the common traps:
❌ Overly complex solutions for simple tasks  
❌ Endless debugging loops when context gets bloated  
❌ Lack of strategic architectural design before jumping straight into code  

To solve this, I distilled my daily experience building complex bioinformatics & software workflows into a systematic agent skill: **`zz-vibe-coding`**! 💡

> *Note: The `zz-` prefix is deliberately added to keep custom user skills easily distinguishable from built-in or default skills.*

---

🎯 **Key Principles of `zz-vibe-coding`**:

1️⃣ **Architecture First**: Evaluate task complexity & design component boundaries before writing code.  
2️⃣ **Make a Plan**: Maintain a structured implementation plan as a clear roadmap.  
3️⃣ **Start Small**: Implement minimal, readable solutions without premature optimization.  
4️⃣ **Modular Design**: Break functionality into focused, single-purpose components.  
5️⃣ **Reference-Driven**: Align with ecosystem standards & authoritative documentation.  
6️⃣ **Strategic Explanations**: Document the strategy and intent for better maintainability.  

---

📦 **How to Install `zz-vibe-coding`**:

You can easily install this skill into **Claude Code, Cursor, Codex, Cline**, or any supported coding agent CLI:

**⚡ Quick Install (`npx`)**:
```bash
# Install the zz-vibe-coding skill from the repository
npx skills add fortune9/Agent_skills --skill zz-vibe-coding

# Or install globally for Claude Code specifically
npx skills add fortune9/Agent_skills --skill zz-vibe-coding --agent claude-code --global
```

**🧩 Claude Code Plugin Marketplace**:
```text
/plugin marketplace add fortune9/Agent_skills
/plugin install programming@fortune9-agent-skills
```

**🛠️ Manual Clone**:
```bash
git clone https://github.com/fortune9/Agent_skills.git
cp -r Agent_skills/programming/zz-vibe-coding ~/.config/claude-code/skills/
```
