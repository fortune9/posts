🚀 Ever wanted to build a custom AI chatbot using R? 🤖

I've just tried to build a chatbot using the power of `shinychat` and `ellmer`, you can have a fully functional, streaming AI interface in minutes. This can be a foundation to add more functions over the interface, such as accessing data in your computer and calling other R functions to make plot

Here’s why you’ll love it:

1️⃣ **Seamless UI with `shinychat`**: Use `chat_mod_ui()` and `chat_mod_server()` to drop a polished chat interface right into your app. No more wrestling with CSS or complex JS!

2️⃣ **Universal LLM Integration with `ellmer`**: Whether it's Anthropic, OpenAI, Google Gemini, or AWS Bedrock, `ellmer` handles the communication. Just create a chat client and pass it to the server.

3️⃣ **Built for Extensibility**: Want to add a new model or provider? It's as simple as updating a lookup list. The architecture is ready for whatever comes next in the world of LLMs.

Check out the code here: https://github.com/fortune9/sample-programs/blob/master/AI/shiny_chatbot.R
